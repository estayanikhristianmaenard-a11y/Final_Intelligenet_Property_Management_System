These records preserve earlier review evidence and original paragraph replacements. Start new manuscript work from [the latest 50-page paper review](../../FINAL_PAPER_REVIEW.md), then check the actual export being edited.

| Record | Historical role |
| --- | --- |
| [45-page export review](UPDATED_PDF_CONTENT_REVIEW.md) | Earlier stored-PDF and diagram checkpoint |
| [49-page export review](UPDATED_MANUSCRIPT_REVIEW.md) | Earlier correction list superseded for the later export by the 50-page review |
| [Rent email amendment](RENT_EMAIL_SCOPE_CHANGE.md) | Original proposal and section-by-section amendment map; subsequent chapter drafts and reviews cover the revised scope |

Original filenames and dated findings are retained for traceability. Archiving does not assert that every task was completed, change the approved workflow, or replace any PDF. Pending reference verification, adviser decisions, presentation fixes and software acceptance checks remain in the active review and application documentation.
