# Information collection template

Open [property-and-tenant-information-template.xlsx](property-and-tenant-information-template.xlsx) in Excel. Property/Manager details are at the top, followed by six unit rows, four utility-account rows and twenty Tenant rows below. Duplicate the sheet for another property; keep the workspace/business field consistent where properties belong to the same owner.

Dropdowns cover record type, property type, provider, individual/shared arrangements and authorization status. Dates use YYYY-MM-DD; account numbers use text format to retain leading zeros. Unknown details should say **For verification**. Review rental dates, opening balances and confirmed advance evidence before entering records into the system. This workbook does not automatically import records or confirm payments.

The blank template can be shared with groupmates. Keep completed copies and authorized bill/payment evidence private; do not put passwords or ID documents in the workbook.
