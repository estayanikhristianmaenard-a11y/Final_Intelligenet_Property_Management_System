# Current Rentara interface previews

Captured from the implemented portal using isolated synthetic data. These are current UI screenshots, not participant evaluation or evidence of live provider delivery. The working database and local configuration are not changed.

Regenerate from the portal directory with `npm.cmd run previews:refresh`. This also refreshes [email previews](../email-previews) and the [icon comparison](../branding/icon-options). Earlier design concepts and the old mockup PDF are under [reports/archive](../archive).
