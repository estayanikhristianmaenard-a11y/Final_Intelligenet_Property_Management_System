# Rentara design: start here

The latest visual proposal is the [property-led workspace SVG](residential-workspace-preview.svg), with a [PNG preview](residential-workspace-preview.png). It replaces the earlier preview at the same paths to keep one current proposal. Four fictional units include three occupied units and four tenants, with configured monthly rent of PHP 18,000. The illustration is decorative, not a floor plan. This is a static proposal, not an implemented portal update or usability result. Rendered and visually reviewed on 29 October 2026.
