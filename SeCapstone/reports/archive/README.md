# Historical reports and concepts

These files are retained for traceability, not as the current interface specification.

- `design-concepts/`: earlier PropertyPro/Rentara dashboard and calendar ideas, old design prompts and dated frontend captures.
- `mockups/PropertyPro_Mockup_Designs.pdf`: superseded mockup export. Its images differ from the implemented Rentara interface.

For current visuals, use [the screenshot index](../mockups/README.md), [email previews](../email-previews) and [approved icon comparison](../branding/icon-options/preview.html). Dated consultation/submission exports remain in their own folders and are not replaced by a new export.

- `design-proposals-2026-10-27.zip`: 76 superseded design exploration files with a SHA-256 manifest. The selected reference is retained in the active design-concepts folder; implemented screens are in mockups.
